    What happens to each file

    Text version

      Always checked, cannot be removed

      After converting, the new file must play all the way through, look like the original (the picture is compared), and hold what this flow asked for. If any check fails, the original stays and Activity shows why. A file is kept even when it isn't smaller; Activity shows the size before and after. When the original is replaced, it's kept for the time set in Settings → Safety.

      {{end}} {{define "workers"}}

      Workers

      A worker converts files. Nothing is converted unless a worker is running.

      Converting is stopped after the update.Press Start to carry on. Basic flows now save MKV files, so .mp4 and .avi files get a new name; all audio tracks are kept. After converting, rescan your libraries in Radarr, Sonarr, Plex or Jellyfin.

      Other computers can be added as workers in a later update.
