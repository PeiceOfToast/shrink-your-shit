        Workers

        A worker converts files. Nothing is converted unless a worker is running.

        Converting is stopped after the update.Press Start to carry on. Libraries set to Basic now save MKV files, so .mp4 and .avi files get a new name; all audio tracks are kept. After converting, rescan those libraries in Radarr, Sonarr, Plex or Jellyfin.

        Other computers can be added as workers in a later update.
