# Mockups for ui-review.md

Open any `.html` in a browser (no server needed; follows the system theme). They use our token names and our palette (`web/src/styles/tokens.css` values, with the scale proposed in `ui-review.md` section 4.2) and invented sample data.

| File | Shows | Review items |
|---|---|---|
| `dashboard.html` | stat tiles, live rows with sub-values and a progress underline, libraries with a saved-share bar, folded charts | C2, C3, C4, C5 |
| `libraries.html` | the list-row grammar, one toolbar with one primary, segmented filters, a phone variant | C1, C6, C13 |
| `jobs.html` | job rows with codec tiles and the size delta, a running row, a failed row, the drawer with card sections | C1, C6, C8 |
| `workflow-editor.html` | the editor toolbar, step rows with number tiles, the graph frame with palette and settings inside it | C10 |
| `mock.css` | the shared styles (tokens, header, rows, pills, tiles) | 4.2 |
